<td width="30%" valign="top"><b>Wafer Defect Detection<br/>& Classification System</b><br/><br/><sub>Semiconductor inspection · Computer vision</sub></td>
<td width="70%" valign="top">

A defect-classification pipeline for semiconductor wafer maps, built to be inspected as much as it inspects.

- ResNet18 (transfer learning), 8 defect classes
- OpenCV preprocessing on raw wafer map images
- Grad-CAM heatmaps — localizes *where* a defect was detected, not just the class
- Streamlit interface: live camera feed, drag-and-drop upload
- Embedded chatbot (GPT-4o-mini) for root-cause analysis on flagged wafers

`Python` `PyTorch` `OpenCV` `Streamlit` `OpenAI API`
