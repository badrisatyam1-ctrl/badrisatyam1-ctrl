## Projects

### Wafer Defect Detection & Classification System
AI-based inspection pipeline for semiconductor wafer maps.

- ResNet18 (transfer learning) classifying 8 defect categories
- OpenCV preprocessing pipeline for wafer map images
- Grad-CAM heatmaps for explainable defect localization
- Streamlit deployment with live camera input and file upload
- Integrated chatbot (GPT-4o-mini) for root-cause analysis assistance

**Stack:** Python, PyTorch, OpenCV, Streamlit, OpenAI API
**Repo:** [wafer-defect-detection](https://github.com/badrisatyam1-ctrl/wafer-defect-detection)

---

### Smart Helmet — Crash Detection & Emergency Response
IoT safety device for motorcycle riders, fully autonomous alert chain.

- MPU6050 IMU for real-time impact detection (6-axis)
- NEO-6M GPS for location tracking
- SIM800L GSM module for automated SMS alerts to emergency contacts
- Sub-second detection-to-alert latency
- Arduino R4 as central controller

**Stack:** C++, Arduino R4, MPU6050, GPS, GSM
**Repo:** [smart-helmet](https://github.com/badrisatyam1-ctrl/smart-helmet)

---

### SENTINEL — Low-Cost Perimeter Surveillance
College mini-project prototype for automated intrusion detection.

- Ultrasonic and PIR sensors for motion/perimeter breach detection
- Arduino/ESP32 controller with alert triggering logic

**Stack:** C++, Arduino/ESP32, Ultrasonic, PIR
